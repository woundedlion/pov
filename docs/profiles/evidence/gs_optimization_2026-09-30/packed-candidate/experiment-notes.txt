Numerical invariants:
Coordinates round to nearest with signed-half addition and truncation, clamp +/-32767.
QSUB16 saturates far differences; an affected lane alone exceeds the ~1988 fixed-unit
kernel radius, so saturation cannot create a false positive in-support contribution.
No all-sphere locality assumption is needed. For local nodes saturation has no effect.
SMUAD result is converted to uint32 before adding z square; maximal three-lane sum
3221225472 fits uint32. Native scalar multiplies each clamped signed lane separately
(within int32), then converts before summing, so no signed C++ overflow occurs.
The explicit bound JSON permits .002 fixed units of floating rounding per coordinate;
this bounds geometric distance error, not final color error near coverage thresholds.
ARM code uses VFMA for quantization then truncating VCVT. Native default compilation
can leave multiply/add separate, so near-half ties may differ by one Q15 LSB; host
quality is not device bit-exact image certification. Four SSAA values remain intact.

Quality: 11 evolved frames through 2000, four synthetic fields at physical 288x144.
Worst channel 167/65535; worst MAE 2.124116/65535; coverage differences <=2/41472;
zero pixels with channel error >4096; global RGB SSIM >=.999999844405.
Quality compares candidate/reference using the same state and orientation, not a
cross-build physics trajectory. Native RGB16 images at frames 320 and 700 are retained.
Display PNGs convert linear16 to sRGB8; heatmaps show max original linear channel error
with fixed 0..170 scale. NPY/CSV/raw preserve quantitative data. Global RGB SSIM is
not sliding-window luminance SSIM. No direct ARM screenshot comparison was performed.

Minimum meaningful tests if a future redesign revives this approach:
- Independent int64 squared-distance oracle at lane extremes, opposite poles, kernel
  boundaries and generated unit vectors; compare packed hit classification and local
  distance to mathematical quantized coordinates, including the 2^31 carry case.
- Quantizer tie/endpoint tests with explicit contract, including negative zero and
  adjacent float values around half-integer scaled coordinates; cover fused ARM and
  unfused host behavior or force identical quantization before claiming exactness.
- Full physical-grid shader comparison against independent float world-node reference
  at several orientations and smooth/sharp/dense states, bound max/MAE and coverage.
- Existing independent physics state hashes, because packing must not alter evolution.
These are proposed only; no repository tests are added for a rejected prototype.
